Speak text aloud and talk to a model by voice

What you get

Section titled “What you get”

Text read aloud on your own machine, and hands-free conversations with a chat model:

  • inga speak turns a text into a WAV file with an OuteTTS model and its vocoder (the files of llama.cpp’s llama-tts), or with a Piper voice (Italian only, such as Giorgio);
  • inga serve answers OpenAI’s POST /v1/audio/speech with them;
  • the web UI’s Voice button listens through the microphone, sends what you say to the chat model, and speaks the answer sentence by sentence while it is still being written; talking over the answer stops it;
  • Deep focus, beside Voice in the chat, shows the maintainer’s avatar saying the answers, its mouth on the sounds.

Speech to text (the “hearing” half) is the one of transcribe-audio.md.

Requirements

Section titled “Requirements”
  • Windows, Linux or macOS; any x86-64 or ARM64 CPU. OuteTTS writes 75 audio tokens per second of speech with a 0.5 B model: about real time on a recent 8-core CPU, slower on an older one, faster on a GPU.
  • About 1 GB of disk and RAM for the speech model and its vocoder, plus a transcription model (Whisper base: 148 MB) and a chat model for the voice chat.
  • For the voice chat: a browser with a microphone, on http://localhost or HTTPS (browsers give no microphone to other pages).

1. Get Inga

Section titled “1. Get Inga”

Download the archive for your system from the Releases page and put inga on your PATH (details); inga --version checks it.

2. Get the models

Section titled “2. Get the models”

The speech model Inga suggests, OuteTTS 0.3 500M, and its vocoder:

The vocoder is downloaded by itself the first time it is needed when you do not give one (--vocoder). OuteTTS 0.2 500M (OuteAI/OuteTTS-0.2-500M-GGUF, the model of llama-server --tts-oute-default) runs too.

Unverified: the 0.3 file name above follows OuteTTS’s own downloader (OuteAI/{model}-GGUF/{model}-{quant}.gguf); it was not checked against the Hub’s file list when this guide was written. If the pull fails, pick the Q8_0 file from the repository’s list (inga search OuteTTS-0.3).

Licences. WavTokenizer is MIT. OuteTTS 0.2 500M is CC-BY-NC-4.0 (no commercial use), which is why Inga suggests 0.3; OuteTTS 0.3 500M is CC-BY-SA-4.0 as far as we know (unverified here: read its model card). Inga prints the file’s licence when it loads it; check the model card before using the audio.

Languages. OuteTTS 0.3 is trained on English, Chinese, Japanese, Korean, French and German (from its model card, unverified here); Italian is not among them. It can speak other languages from a voice (a speaker profile) recorded in that language, with that voice’s accent: for Italian, make or use an Italian voice (§4).

3. Speak a text

Section titled “3. Speak a text”

The text can come from a file (-f story.txt) or the standard input. A long text is spoken in pieces of whole sentences, joined in one file. (The times above depend on the machine.) Punctuation sets the pieces but is not read. The model reads words, so numbers are written out in the text’s language:

Language How it is chosen Example
English (the default) — 3.5 → “three point five”, 1,000 → “one thousand”
Italian --language it, a voice file with "language": "it", or a model whose only language is Italian 3,50 → “tre virgola cinquanta”, 1.000 → “mille”, 2026 → “duemilaventisei”

The summary line says which was used. Other languages are read with English numbers (write the numbers out in words if that matters).

Inga reads the model’s prompt format (0.2 or 0.3) from the file: the chat template outetts-0.3, else the version in the model’s or the file’s name, else its vocabulary. A file none of these tell apart is refused with what was read; rename it after its version (OuteTTS-0.3-500M-Q8_0.gguf) and it is read as that version.

4. Choose a voice

Section titled “4. Choose a voice”

Without a voice the model picks one; Inga keeps the voice of the first sentence for the next ones, so a text keeps one voice. The same text and seed (--seed) give the same audio. To keep a voice you like:

A saved voice records the language its text was read in ("language"), and texts read with it use that language’s numbers unless --language says otherwise. For Italian: inga speak MODEL "Questa è la voce che voglio." --language it --save-voice it.json, then --voice it.json.

Speaker files of OuteTTS (interface.save_speaker) work too. Put them in ~/.cache/inga/voices/NAME.json (~/.cache/inga/voices by default) to use them by name: --voice NAME, or "voice": "NAME" over HTTP.

5. Serve it to OpenAI clients

Section titled “5. Serve it to OpenAI clients”

The answer is a WAV file (24 kHz, 16-bit, mono); "response_format": "pcm" gives the same samples without a header. OpenAI’s voice names are the server’s default voice. Inga writes no MP3: a client that asks for mp3, opus, aac or flac gets a 400 saying so. Inga’s "language": "it" reads the numbers in Italian; the answer’s X-Inga-Text-Language header says which language was used. The web UI sends the page’s language.

6. Talk to a model in the browser

Section titled “6. Talk to a model in the browser”

Start the server with a chat model (inga serve Qwen3-8B-Q4_K_M.gguf) and open http://localhost:8080/.

The quickest way: press Voice (or Deep focus). Without voice models, both show the same Prepare the voice card: the models Inga recommends for the page’s language, in plain words, with the total size and one Download and use; nothing is downloaded before the click. On an Italian page that is Whisper base and the Piper voice Giorgio; on any other, Whisper base and OuteTTS with its vocoder (the table VOICE_RECOMMENDED of the web UI’s voice.js). A transcription model too slow for talking on this computer (below real time, measured on the turns spoken or with Measure speed, or estimated from another model measured here) is said in plain words on Models → Voice and in Deep focus (“slow for talking on this computer: about 62 s per sentence”), with the recommended model in one click; it is never switched without it. The transcription model’s Language is Automatic, or the one language of the voice chosen (Giorgio: Italian), or the one you pick.

Noise: a sound needs a quarter of a second above the room’s level to start a turn, a turn with less than half a second of voice is not sent, and a turn Whisper says holds no speech, or a short one that says only one of its noise phrases (“Grazie.”, “Thank you.”), is dropped; the bar says “Noise ignored”. With Silero here (in the “Prepare the voice” set), the server finds the speech first (vad=true). Mute (the M key) turns the microphone off for real; Models → Voice’s Listening chooses Always listening (you can interrupt) (the default), Take turns (the microphone off while Inga thinks and speaks) or Hold to talk (hold Space, or the voice bar’s button).

  1. Models → Voice chooses the transcription model and the speech model: the machine’s models, or the suggested ones with Download and use. The vocoder is no choice of its own: it follows the speech model. Download and use on OuteTTS downloads OuteTTS and its vocoder in one click, the card counting both sizes; a Piper voice (Giorgio) needs none, and the page says so (choosing it clears the vocoder, whose file stays on disk). When the machine has one of each, pressing Voice chooses them by itself. The Voice (speech in and out) section, under the library, has one bordered panel per model: Hearing: transcription model and Speaking: speech model, each saying what the model is for and when it is needed (a chat model that hears audio needs no transcription model); a line under the speech model says which vocoder it speaks with, that it needs none (Piper), or the one to download. In the library the voice models sit in the Voice: transcription, Voice: speech and Voice: vocoder boxes, each with Use for voice. Each panel shows the model in use as a card (Change, Stop using) and one list of every model of its kind, as the embedding model does (a state badge — Not downloaded, Downloading…, Downloaded or the folder it was found in, In use — and one action), with its languages, size, licence and speed here: Measure speed transcribes ten seconds of faint noise with the transcription model, and the speech model’s Listen says a sample sentence in the page’s language and measures how many times faster than real time it speaks. OuteTTS has no fixed voice list: it picks a voice at the first sentence and keeps it, and speaker files in ~/.cache/inga/voices give others.
  2. Press Voice beside Send (or Alt+Shift+V). The bar over the input says Listening…; speak, then pause: after 0.8 s of silence the page sends what you said. No button to press when you stop.
  3. Thinking…: the speech is transcribed and sent as your message. A chat model that hears audio (Gemma 3n / 4, Voxtral, Qwen2-Audio, …) gets the recording itself, without a transcription. With a streaming transcription model (Nemotron Speech Streaming, a cache-aware Parakeet model) the page sends the speech while you say it, over the live WebSocket (/api/inga/transcriptions/live), and shows what it heard so far under Hearing you…; when you stop, the text is ready without an upload.
  4. Speaking…: each sentence of the answer is spoken as soon as it is written. The bar shows the time from the end of your speech to the first sound.
  5. Talk over the answer to stop it; Esc or End ends the voice mode.

Every answer also has Read aloud, which speaks it with the same speech model.

Options worth knowing

Section titled “Options worth knowing”
Option Meaning
inga speak MODEL TEXT -o F Speak a text into a WAV file (- the standard output)
--format pcm Raw 16-bit samples instead of a WAV file
--vocoder F The vocoder (default WavTokenizer large, downloaded)
--voice V, --save-voice F Use a voice, keep the voice of this text
--language it|en The text’s language, for its numbers in words
--temp X, --seed N Sampling temperature (0.4), seed
inga serve ... --tts M Answer /v1/audio/speech (with --vocoder, --voice)

How it works

Section titled “How it works”

OuteTTS is a small Qwen2.5 language model whose vocabulary holds 4100 audio tokens. The prompt gives it the words (hello<|text_sep|>there) and, for a voice, a few words with their durations and audio tokens; the model continues each word with its duration and its audio tokens. WavTokenizer turns the tokens into sound: a codebook, convolutions, attention and ConvNeXt blocks give each token a spectrum, and an inverse FFT makes 320 samples of it (75 tokens a second at 24 kHz). Inga runs the language model with its own engine and the vocoder on the CPU. The design is in 2026-10-12-voice-design.md.

Troubleshooting

Section titled “Troubleshooting”
  • “is not a text-to-speech model Inga runs”: the file is neither OuteTTS (its vocabulary has no audio tokens) nor a Piper voice with its JSON beside it. Piper runs Italian voices only; Kokoro and other voices are not run.
  • “is not a vocoder Inga runs”: --vocoder must be a WavTokenizer GGUF file (general.architecture = wavtokenizer-dec).
  • The voice button says the microphone needs HTTPS: open the page on http://localhost:PORT on the machine itself, or behind HTTPS.
  • “Voice needs … (Models → Voice)”: open Models → Voice and choose or download the models it names.
  • Slow speech: the speech model writes 75 tokens per second of audio; on an older CPU the first sound of a long sentence takes a few seconds. A GPU (--device) helps the chat model; the speech model runs on the CPU.
