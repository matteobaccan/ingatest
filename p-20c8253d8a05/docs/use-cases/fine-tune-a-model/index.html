Fine-tune a small model on your data

What you get

Section titled “What you get”

A LoRA adapter trained on your own examples, on the CPU, with nothing but Inga: no Python, no PyTorch, no GPU. inga finetune reads a JSONL dataset (plain texts, prompts with their completions, or chat conversations), learns the adapter’s two small matrices on the projections you choose while the model’s own weights stay as they are (quantized or not), and writes the adapter in llama.cpp’s GGUF format: --lora loads it in Inga (apply-lora-adapters.md) and in llama.cpp.

Recover-LoRA is the same training with a teacher: an adapter that brings a 2- or 3-bit model’s predictions back toward its full-precision original, kept as a separate file of a few MB.

Requirements

Section titled “Requirements”
  • Windows, Linux or macOS; any x86-64 or ARM64 CPU. A training step reads every weight of the model forward and backward: small models (up to 1–2 B parameters) are the practical size.
  • A plain dense model: Llama, Mistral, Qwen2, Qwen3, SmolLM, Phi-3 and the like. Mixtures of experts, Gemma, hybrid (Qwen3.5) and recurrent models are refused, saying why.
  • Memory for the model plus the activations of one example (a few hundred MB at --ctx 512 for a 1 B model).

1. Get Inga

Section titled “1. Get Inga”

Download the archive for your system from the Releases page and put inga on your PATH (details); inga --version checks it.

2. Get a model and write the dataset

Section titled “2. Get a model and write the dataset”

One example a line, in any of three forms (mixed freely):

  • messages: rendered by the model’s chat template; only the assistant turns are learnt (with the token that ends them, so that the model learns to stop).
  • prompt / completion: only the completion is learnt, then the end of text.
  • text: every token is learnt.

A .txt or .md file is read as one text cut into pieces of --ctx tokens.

3. Train

Section titled “3. Train”

Each step prints its loss (captured with a two-layer test model and a two-line dataset, on a busy machine: the speed means nothing here):

The loss should go down over the epochs; if it stops falling, more epochs only learn the examples by heart. A run stopped halfway (Ctrl+C, a reboot) continues with --resume: the checkpoint my-lora.ckpt.gguf holds the optimizer’s state, and the examples come in the same order as if it had never stopped.

4. Check that it works

Section titled “4. Check that it works”

inga perplexity with and without --lora on held-out text tells how much it changed (measure-model-quality.md).

5. Recover a low-bit model’s quality (Recover-LoRA)

Section titled “5. Recover a low-bit model’s quality (Recover-LoRA)”

With --teacher, the adapter learns the full-precision model’s predictions instead of the dataset’s tokens, at the positions the dataset learns; any text works as data:

The loss printed is then the KL divergence from the teacher. Both models must share the vocabulary (the same model at two precisions); the teacher runs too, so the memory of both is needed.

Options worth knowing

Section titled “Options worth knowing”
Option Effect
--data FILE The dataset (JSONL, or a .txt / .md text).
-o FILE The adapter (default <model>-lora.gguf); the checkpoint goes next to it.
--lora-targets LIST q,v (default); k, o, gate, up, down, output, attn, ffn, all.
--rank N, --alpha X The adapter’s rank (8) and scale alpha / rank (alpha 16).
--epochs N, --steps N Passes over the data (1); a cap on the steps.
--batch N, --lr X Examples per step (4); AdamW’s learning rate (0.0002).
--ctx N The longest example in tokens (512); longer ones are cut.
--save-every N, --resume A checkpoint every N steps (else each epoch); continue from it.
--teacher M Recover-LoRA: distil from M.
--chat-template T The template of the chat lines (chatml, llama3, Jinja text).

Troubleshooting

Section titled “Troubleshooting”
  • “fine-tuning runs plain dense transformer layers …”: the model is a mixture of experts, a Gemma, a hybrid or another kind the trainer does not run.
  • “this model has no chat template”: give one with --chat-template chatml, or write prompt / completion lines.
  • “file:LINE: a line with neither messages, prompt and completion, nor text”: that line is in none of the three forms.
  • “… was trained with –batch 4, not 2” (or another number of examples): --resume needs the same dataset and batch; remove the .ckpt.gguf file to start over.
  • The loss does not go down: raise --lr (try 0.001), or add targets (--lora-targets attn,ffn).
