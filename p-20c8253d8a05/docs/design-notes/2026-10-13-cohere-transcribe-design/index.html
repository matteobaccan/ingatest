Speech to text, part 3: Cohere Transcribe

Status: built for 0.30.0 on synthetic weights (feat/cohere-transcribe); what is left is in §10. Code: crates/inga-vision/src/cohere.rs (the model), crates/inga-vision/src/parakeet.rs (Conformer, the encoder both use), crates/inga-vision/src/parakeet/frontend.rs (the file’s filter bank and window), crates/inga-formats/src/cohere_hf.rs (the Hugging Face directory), crates/inga-engine/src/speech.rs (Recognizer::Cohere), crates/inga-server/src/speech.rs (the language of a request that gives none), crates/inga-server/src/webui.html (the Voice section’s suggestion).

1. Why

Section titled “1. Why”

Issue #421 asks for handy-computer/cohere-transcribe-03-2026-gguf: Inga 0.26.2 says NOT SUPPORTED: architecture cohere_asr. The TODO.md item (0.30.0, the last of the speech work) asks for handy-computer’s GGUF (cohere_asr, transcribe.cpp’s) and the Hugging Face directory, in inga transcribe and /v1/audio/transcriptions beside Whisper and Parakeet, its encoder checked against Parakeet’s to reuse it, the licence checked first.

Licence: Apache-2.0 (Cohere’s model card and documentation; transcribe.cpp’s convert-cohere.py writes general.license = apache-2.0). The weights on Cohere’s repository are gated (a contact form); handy-computer’s GGUF files are not. Nothing to say at load beyond the usual model card.

The model: Cohere Transcribe 03-2026, about 2B parameters, 14 languages (en, fr, de, es, it, pt, nl, pl, el, ar, ja, zh, vi, ko); cohere-transcribe-arabic-07-2026 has the same layout with [en, ar]. A 48-block FastConformer encoder (d = 1280) and an 8-layer Transformer decoder (1024 wide, 8 heads, ReLU), a SentencePiece vocabulary of 16384 pieces. No language detection, no translation, no timestamps (the prompt says <|notimestamp|>).

The reference read: transcribe.cpp (MIT) at f1dcd15: src/arch/cohere/ (weights.cpp, encoder.cpp, decoder.cpp, model.cpp), src/transcribe-mel.cpp, src/transcribe-repetition-guard.h, src/transcribe-decode-budget.h and scripts/convert-cohere.py. transcribe.cpp validates its port against Hugging Face Transformers’ native CohereAsrForConditionalGeneration (LibriSpeech test-clean WER 1.26 % in BF16, Cohere’s own 1.25 %).

2. The file (general.architecture = cohere_asr)

Section titled “2. The file (general.architecture = cohere_asr)”

Keys, all read: stt.cohere.encoder.{n_layers, d_model, n_heads, d_ff, conv_kernel, subsampling_factor, subsampling_channels, pos_emb_max_len, use_bias}, stt.cohere.decoder.{n_layers, hidden_size, n_heads, inner_size, max_sequence_length, activation}, stt.cohere.decoder_start_token_id, stt.cohere.head.{log_softmax, tied_weights}, stt.frontend.* (Parakeet’s, plus pad_mode), general.languages, stt.variant, tokenizer.ggml.{tokens, token_type, eos_token_id, ...}.

Tensors: the encoder under Parakeet’s names (enc.pre_encode.conv.{0,2,3,5,6}, enc.pre_encode.out, enc.blocks.N.{norm_ff1, ff1.linear1/2, norm_attn, attn.linear_{q,k,v,out,pos}, attn.pos_bias_{u,v}, norm_conv, conv.pointwise1, conv.depthwise, conv.pointwise2, conv.bn.*, norm_ff2, ff2.*, norm_out}), then enc_dec_proj.{weight,bias}, dec.embed.{token.weight, pos_enc, norm.*}, dec.blocks.N.{norm_self, self_attn.{q,k,v,out}, norm_cross, cross_attn.{q,k,v,out}, norm_ff, ff.dense_in, ff.dense_out} (weights and biases), dec.final_norm.*, head.bias (the head’s matrix is the token embedding, tied), and the frontend’s frontend.mel_filterbank ([128, 257], the checkpoint’s) and frontend.window (400 values). Matrices in any type Inga reads (F32, F16, BF16, Q8_0, K-quants: the published files are BF16, F16, Q8_0, Q6_K, Q5_K_M, Q4_K_M).

3. The encoder: Parakeet’s, reused

Section titled “3. The encoder: Parakeet’s, reused”

Checked tensor by tensor and against transcribe.cpp’s cohere/encoder.cpp (a thin glue over the same conformer::build_conformer_block its Parakeet uses): the encoder is Parakeet’s FastConformer with use_bias = true (biases on every linear layer and on the convolutions, none on linear_pos), batch norm in the convolution module, full attention, symmetric depthwise padding, the subsampling by 8 with (1, 1) padding, Transformer-XL relative positions, no xscaling. So Parakeet’s encoder becomes a Conformer (frontend, subsampling, blocks, attention context) that both models hold; Parakeet’s code is unchanged in behaviour (its tests, which match transcribe.cpp word for word, pass untouched).

One difference, from transcribe.cpp: Parakeet keeps the encoder rows of the valid feature frames (NeMo masks the padding frame); Cohere runs all the frames (the last one zeroed, see §4) through the encoder, as transcribe.cpp does and as its WER parity with Transformers shows. Then enc_dec_proj maps each row to the decoder’s width.

4. The audio front end

Section titled “4. The audio front end”

Parakeet’s (NeMo’s) features: pre-emphasis 0.97, zeros of n_fft / 2 on each side (pad_mode = constant; reflect is refused), a symmetric Hann window of 400 in a 512-point FFT every 160 samples, the power through the mel filters, ln(x + 2^-24), per-feature normalization (mean, unbiased deviation plus 1e-5) over the samples / hop valid frames, the last frame zeroed. When the file has frontend.mel_filterbank and frontend.window, they replace the computed filters and window (transcribe.cpp does the same: the checkpoint’s exact values). A Parakeet file with these tensors would use them too.

5. The decoder

Section titled “5. The decoder”

As transcribe.cpp’s decoder.cpp (pre-norm, LayerNorm eps 1e-5):

  • x = LN_embed(tok[id] + pos_enc[position]) (a stored position table, no scaling);
  • each layer: x += SelfAttn(LN1(x)) (causal, with a cache of keys and values), x += CrossAttn(LN2(x), enc) (keys and values of the encoder rows computed once per layer), x += W_out · act(W_in · LN3(x) + b_in) + b_out (ReLU, or SiLU when the file says silu / swish); attention scaled by 1 / sqrt(head_dim);
  • logits = tok · LN_final(x) + head.bias, then log-softmax (head.log_softmax).

The prompt (Transformers’ get_decoder_prompt_ids, ten tokens): ▁, <|startofcontext|>, <|startoftranscript|>, <|emo:undefined|>, <|LANG|> twice, <|pnc|> (punctuation and capitals), <|noitn|>, <|notimestamp|>, <|nodiarize|>. A file whose vocabulary lacks one of them is refused at load.

Greedy decoding until eos (the tokenizer’s), within transcribe.cpp’s budget: max(512, 12 tokens per second of audio), capped by max_sequence_length minus the prompt. transcribe.cpp’s repetition guard: a block of up to 128 tokens repeating at the end (8 copies, at least 64 tokens, at most 192, at least 4 copies) stops the decoding with the repeats dropped; at the budget, a block repeating three times over 32 tokens or more is dropped.

The text: the pieces joined, ▁ as spaces, <0xHH> as bytes; control and unknown tokens and <|...|> tags left out; the leading space trimmed.

6. Long audio, segments, timestamps

Section titled “6. Long audio, segments, timestamps”

The model has no timestamps; upstream recommends clips of 35 s (the encoder’s table would allow 400 s). Inga cuts longer audio itself: pieces of at most 35 s, each ending at the quietest 100 ms (lowest energy) of its last 5 s. Each piece is one segment whose start and end are the piece’s: subtitles get coarse times. Word timestamps are refused (Error::Usage: “Cohere Transcribe gives no timestamps”); so is translation. --vad works as for the other models (the speech only, the times mapped back).

7. The language

Section titled “7. The language”

The model does not detect it. A given language is an ISO-639-1 code, a locale (it-IT) or Whisper’s English name (italian); it must be one of general.languages and have its <|xx|> token, else Error::Usage lists the model’s. Without one (or auto): English when the model knows it (transcribe.cpp’s default), else its first language; the transcript says the language used, with probability 0 (not detected, not given). /v1/audio/transcriptions and the live route, for a model that needs a language (SpeechModel::needs_language), take the request’s Accept-Language (its first tag the model knows) when the form gives none: the browser’s language, which the web UI’s voice mode sends without asking.

8. The Hugging Face directory

Section titled “8. The Hugging Face directory”

CohereLabs/cohere-transcribe-03-2026 (config.json with model_type = cohere_asr or CohereAsr… architectures, or the NeMo-style encoder / transf_decoder / preprocessor sections; generation_config.json; tokenizer.model; model.safetensors in BF16) is presented as the GgufFile convert-cohere.py would write (cohere_hf.rs, as whisper_hf.rs does for Whisper): the keys from the configuration (d_ff = d_model * ff_expansion_factor, the window and hop from seconds, pre-emphasis 0.97, f_max the Nyquist frequency, pad_mode = constant), the tensors renamed (encoder.layers.N.feed_forward1.linear1 → enc.blocks.N.ff1.linear1, transf_decoder._decoder.layers.N.first_sub_layer.query_net → dec.blocks.N.self_attn.q, …), log_softmax.mlp.layer0.weight (the tied copy) skipped, preprocessor.featurizer.fb as frontend.mel_filterbank (the window is computed: the checkpoint’s has a flat top, transcribe.cpp computes the symmetric Hann). The data is not converted. The vocabulary comes from tokenizer.model, a SentencePiece ModelProto read by a small protobuf reader (pieces, scores, types).

9. Where it appears

Section titled “9. Where it appears”
  • inga transcribe AUDIO --model hf://handy-computer/cohere-transcribe-03-2026-gguf (--language it); the summary line describes the model; --word-timestamps and --translate are refused; --stream transcribes the audio so far again (it is not a streaming model).
  • inga serve --whisper FILE and the speech model served alone: /v1/audio/transcriptions (all formats; verbose_json segments are the pieces of §6), stream=true and the live WebSocket through the re-transcription of the audio so far.
  • inga list / inga scan / the library: supported (speech to text: inga transcribe), use speech; a Hub search result cohere_asr is supported (speech to text); inga run on the file says it is a speech-to-text model.
  • The web UI: the library lists it with the speech models, so the Voice section can choose it; the section suggests cohere-transcribe-03-2026-Q8_0.gguf (2.41 GB, “14 languages, the most accurate; your browser’s language is used”).

Tests (synthetic weights, crates/inga-vision/src/cohere.rs, crates/inga-vision/src/parakeet/frontend.rs, crates/inga-formats/src/cohere_hf.rs, tests/transcribe.rs): a synthetic cohere_asr file of the real layout (the converter’s names, shapes and keys; 16 mel bins, a 2-block encoder, a 2-layer decoder) — (a) its encoder rows are, number for number, those of a synthetic Parakeet file with the same encoder weights; (b) the decoder’s logits at every step, with its caches and the backend’s products, match a plain scalar reference (no cache, loops in f64) within 1e-4, and the greedy tokens are the same; (c) the prompt, the languages (codes, locales, names, unknown ones), the text (tags and control tokens dropped, bytes), the repetition guard, the cut of long audio, the refusals; (d) the frontend uses the file’s filter bank and window; (e) a Hugging Face directory written from the same weights (F32 safetensors with the tied copy and a batch norm’s counter, a tokenizer.model) transcribes as the GGUF file; (f) inga transcribe (languages, refusals, subtitles, the directory), inga run on the file, the server’s Accept-Language.

10. Left

Section titled “10. Left”
  • The real files: cohere-transcribe-03-2026-Q8_0.gguf on jfk.wav against transcribe.cpp’s transcribe-cli -l en (group A of real-checks.yml now includes the cohere files), and the Hugging Face directory (gated) against the GGUF.
  • Speed: the encoder runs on the CPU only, as Parakeet’s; 48 blocks of 1280 make it the slowest speech model Inga runs. The GPU and batched decoding are not done.
  • The <|nopnc|> prompt (no punctuation) and inverse text normalization (<|itn|>) are not offered.
