Real-world checks

Back to the roadmap’s index: TODO.md.

What the releases could not check where they were built (no Hugging Face access, one Linux x86-64 machine, no real clients, no LAN, no phones), gathered on 2026-10-11 from the 30 lines named 0.2.1 … 0.26.1 (the checks tagged with the release that shipped them since) and the notes of what was left when 0.22.0– 0.26.0 shipped. Each bullet names the release(s) it came from; fixes for whatever a check finds go into the next release. A new release adds its own unchecked items here, as bullets in the right group tagged with the release (docs/RELEASING.md, step 6); a check that passes is removed (its result goes into the pull request or the release notes that fix what it found).

  • [runner]: the maintainer’s self-hosted runner can close it (his Windows PC: Xeon W-2123, 32 GB of RAM, Quadro P1000 with 4 GB, his model files on a disk of their own, Ollama, LM Studio and Python installed), through .github/workflows/real-checks.yml or gpu.yml; files larger than the workflow’s size limit (20 GB by default) need the limit raised or a bigger machine. P1000 runs: from 0.34.0 (the maintainer, 2026-10-16); the pending ones are tagged (0.34.0) in group E.
  • [manual]: needs the maintainer in person (other machines, phones, other operating systems, interactive clients); the order to run them is in docs/maintainer-checklist.md.
